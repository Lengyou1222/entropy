What it does它能做什么

所有能力共用一个原生守护进程与一套 IPC 协议；界面只是它的其中一张脸。

浮窗

双面板悬浮控制台

左侧大面板装六节调节，右侧小面板紧贴屏幕右缘装信息、我的、开关与 CPU 排行。小球可拖动、双击切档、点面板外收起。

常驻

灵动岛

固定在顶部、不可拖动的一小块安全显示区，显示项可多选，展开后按内容量自适应缩放。

调度

按应用调速

每个应用一份帧率档案；开发模式页直接下发 CPU/GPU 频率上限，调度器 honor 显式值而不是自作主张。

记录

帧率曲线

记录页画曲线、给最低与最高值，可按单个应用归档，采样来自真节点，取不到就是「—」。

录屏

高帧率录屏

MediaProjection 采集，帧率跟随屏幕当前真实刷新率，上限 240 FPS，码率可手动指定。

隐私

防录屏

给浮窗与灵动岛加 FLAG_SECURE。录屏与截屏拿不到这几层内容，合成结果里对应区域是黑块。

快捷键

音量键唤出

音量加键打开、减键关闭。这是可观察行为，不拦截 KeyEvent，按键照常调音量。

授权

四种等级并存

无授权 / ADB / Shizuku / root（含 Magisk 模块）。当前处在哪一级、少了什么，界面里如实写着。

外观

十七套配色 + 明暗主题

默认樱吹雪。高亮色可自定义，但温度梯度与熔断色不参与改色——那三档是安全语义。

Interface界面

浅色 + 樱吹雪方案，实机截图。

Boundaries安全边界

这些是刻意保留的约束，不是待清理的技术债。

1

不改游戏文件。UE4 的 *.ini、config.lua 一律不碰。

2

不注入游戏进程。反外挂会把它当外挂信号；插帧与调度走内核侧接口，不往目标进程塞代码。

3

不伪造温度。读到什么报什么，取不到显示「—」。

4

95 ℃ 熔断钳三次。App、Daemon、CLI 各一道，任何一处被绕过都还有下一道。读数取所有热区的最大值，真实机型上那通常是 SoC / GPU 结温，负载起来 60~80 ℃ 是常态，所以默认熔断线 85 ℃、软上限 70 ℃、提醒线 60 ℃；越线只做一件事——把调度还原成系统默认。

5

节点写入有白名单。只接受 /sys/ 与 /proc/、拒绝 ..、值必须整型；连接侧保留 UID 门。

6

包名先过正则。^[A-Za-z0-9._:-]{1,128}$，含 shell 元字符一律拒绝。

Build自己编译

需要 JDK 17、Android SDK 35、NDK，Gradle 由 wrapper 带。

bash scripts/build-daemon.sh   # 先编 native：产出 daemon/out/<abi>/
bash scripts/build-apk.sh      # 一条命令出 release + debug APK 到 dist/
路径

影子目录

构建脚本把源码同步到一个纯 ASCII 目录再交给 Gradle——AGP 在 Windows 上会直接拒绝非 ASCII 工程路径， 这不是警告而是 apply plugin 阶段失败。源码目录保持原样。

踩坑

改过 native 要先删产物

rm -rf daemon/out 再编。脚本只搬运产物，不感知 native 源文件的变化， 留着旧目录会得到一个「编过了但没带上改动」的 APK。

分发

只有 arm 产物

守护进程是 Native 的可执行文件树，不走 JNI 库路径：编好后复制进 assets/native/<abi>， 授权后释放到 /data/local/tmp。

签名

读不到就退回 debug

签名材料在 keystore.properties 与 entropy.keystore，都被 gitignore。 缺了它们构建照样成功，只是那份包不能覆盖安装正式签名的包。
